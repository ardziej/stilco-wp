## Jak pobrać ponownie (REST)

Wymaga personal access tokena (Figma → Settings → Security → Personal access tokens, scope `file_comments:read`). Zapisz jako `FIGMA_TOKEN` w `.env`, potem:

```sh
python scripts/figma_comments.py
```
